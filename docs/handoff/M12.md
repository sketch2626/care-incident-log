# Handoff: M12 pictures, a skill (second account, branch `other/M12`)

Read `docs/handoff/_common.md` first. Then read only these: `docs/mary-roadmap.md` M12 and M13; `docs/skills-design.md` sections 3-8 (internet only through `ctx.fetch`); `docs/how-to-make-a-skill.md`; and `skills/voice_comfort/`.

**Andy (2026-10-29):** "show me a picture of this bird." He's fine with not doing a raw image search, because Wikipedia is safer.

**Build the `pictures` skill** (`skills/pictures/`):
- **Action `show_picture(what)`:** find the best matching Wikipedia article and take its **lead image**. Use `ctx.fetch` with allowed hosts `en.wikipedia.org`, `upload.wikimedia.org` and `commons.wikimedia.org`, the REST page summary or the action API, and a sensible thumbnail width of about 1600.
  - Serve the image to the page through the server (local route or store). Don't hotlink, so the allow-list, size cap and timeouts always apply.
  - Get the photo's **credit and license** (Commons `extmetadata`) and show it small under the picture.
- **Screen:** the picture full screen with a big plain caption (the article title) and a big "Back to Mary" button (≥64px). Mary's face scoots aside or sits in a corner while it's shown.
- **`view()`:** tells Mary what's on screen: the title plus a two-sentence summary, so she can talk about it naturally.
- **More actions:** `next_picture` (another image of the same subject, if the article or Commons category has one) and `close_picture`.
- **Safety:**
  - Lead images only. Refuse queries for clearly adult or gory things with a kind line.
  - Never send anything but the search words.
  - Offline: "I need the internet to find pictures."
  - Time limits: `"slow": true`, the 8 s guard.
- **Tests:**
  - Contract tests pass.
  - Mocked fetch for found, not found and offline, plus the credit text.
  - The image is size-capped.
  - `node --check` on `screen.js`.
- **Model:** Opus xhigh for the fetch, search and credit logic if it's tricky; Sonnet for the screen and tests.

**Finish:** commit with the subject `DONE: M12 pictures skill`. If you need Andy to see something first, use `WAITING:` instead and stop.
